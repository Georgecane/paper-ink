# Paper & Ink

A free, open-source writing environment inspired by the tactile feeling of a typewriter and paper stationery.

> **Status:** Early project setup. Product research, interaction specifications, and implementation are not complete yet.

## Goals

- A focused, tactile writing experience with carefully designed paper, ink, and typography.
- Fast startup and responsive editing on modest hardware.
- Local-first storage, with optional synchronization considered separately.
- A modular interface and document model that can evolve without locking the application to one desktop shell.
- An accessible, internationalized experience, including right-to-left writing.

## Planned technology direction

- **UI:** TypeScript, JavaScript, and web standards.
- **Desktop shell:** Tauri 2 (no Electron dependency).
- **Native integration:** Rust, limited to capabilities that benefit from native execution.

The final framework and editor architecture will be selected after the product and interaction research is documented.
